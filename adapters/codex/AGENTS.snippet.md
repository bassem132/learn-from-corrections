## Learning from corrections

- When I correct you ("no, use X here", "don't do that again", "from now on…"), turn the reusable ones into a one-line rule with its reason, e.g. `- Use pnpm, not npm — the lockfile is pnpm-lock.yaml.`
- Before adding it, check this file for a duplicate or a conflicting rule. Strengthen or replace instead of adding twice.
- Show me the exact line and the section it goes in, and save it only after I say yes.
- Keep this file under ~150 lines. Propose merging rules when it grows.
- Don't save one-off task details, secrets or machine-specific paths.
